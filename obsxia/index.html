安装与配置指南

Windows 系统安装步骤

OBS 的安装过程非常简单，只需按照以下步骤操作即可完成环境搭建。

  1. 点击上方下载按钮，获取 Windows 安装包。
  2. 运行下载的 .exe 安装程序，选择“安装 OBS Studio”。
  3. 在安装向导中，建议勾选“启动 OBS Studio”。
  4. 首次启动时，OBS 会自动检测您的显卡驱动，建议点击“下一步”让向导自动配置编码器。

常见编码器设置建议

对于大多数主播，使用硬件编码器可以获得更流畅的性能，而 CPU 编码器则提供更好的画质控制。

使用 NVIDIA 显卡：

在设置 -> 输出 -> 录制中，将“录制方式”设置为“使用 NVENC 编码”，并将 NVENC 编码器设置为“NVENC H.264 (new)”。

使用 AMD 显卡：

将编码器设置为“AMF H.264”，确保在 Windows 图形设置中将 OBS Studio 设置为“高性能”模式。

快速启动命令

如果您需要通过命令行快速启动 OBS 或进行静默安装，可以使用以下命令：

obs64.exe --startstreaming --multiview

上述命令将启动 OBS 并直接进入推流状态和四分屏视图。

常见问题 (FAQ)

下载的 OBS 无法启动怎么办？

首先请检查您的显卡驱动是否为最新版本。如果安装了杀毒软件，请尝试暂时关闭后再试。对于 Windows 用户，确保安装的是 64 位版本。如果问题依旧，尝试在 OBS 安装目录下找到 “obs.exe” 并以管理员身份运行。

OBS 下载需要付费吗？

完全不需要。OBS Studio 是完全免费的开源软件，您可以无限制地使用其所有功能。

如何设置推流密钥？

推流密钥通常在您的直播平台（如 Twitch、YouTube、B站）的后台设置中获取。在 OBS 的“设置”->“推流”中，将服务选择为“自定义”，然后将密钥粘贴到“推流密钥”输入框中。
